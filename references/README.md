# রেফারেন্স লাইব্রেরি (সব ভিডিওর জন্য)

অন্য কোনো ভিডিও, বিজ্ঞাপন বা থাম্বনেইলের স্টাইল ভালো লাগলে এখানে জমিয়ে রাখুন। Claude নতুন ভিডিও বানানোর সময় এগুলো দেখে স্টাইল বুঝে নেবে:
- রং
- টেক্সট অ্যানিমেশন
- কাটিংয়ের গতি
- ট্রানজিশন
- লেআউট

| ফোল্ডার | কী রাখবেন |
|---|---|
| `thumbnails\` | পছন্দের থাম্বনেইলের স্ক্রিনশট |
| `intros-outros\` | ইন্ট্রো বা আউট্রোর ছোট ক্লিপ |
| `ads-promos\` | প্রোডাক্ট বিজ্ঞাপন বা SaaS প্রোমোর ক্লিপ |
| `motion-graphics\` | টেক্সট অ্যানিমেশন, লোয়ার থার্ড, চার্ট, ট্রানজিশনের উদাহরণ |
| `editing-style\` | কাটিং, জুম, B-roll, পেসিংয়ের উদাহরণ |
| `captions\` | পছন্দের সাবটাইটেল স্টাইলের স্ক্রিনশট |

## নিয়ম
1. **ছোট ক্লিপ রাখুন** (১০–৩০ সেকেন্ড), পুরো ভিডিও না। Windows-এ `Win + Alt + R` চাপলে স্ক্রিনের একটা অংশ রেকর্ড করা যায়। স্ক্রিনশটের জন্য `Win + Shift + S`।
2. **ফাইলের নামেই লিখুন কী ভালো লেগেছে।** যেমন `gold-text-reveal_apple-watch-ad.mp4`, `fast-cuts-zoom_mkbhd.mp4`।
3. **লিংকগুলো `links.md`-তে লিখুন।** সাথে এক লাইনে লিখুন কী ভালো লেগেছে।
   - Chrome সংযুক্ত থাকলে Claude লিংক খুলে স্ক্রিনশট নিয়ে নিজেই দেখে নেবে। সংযোগের নিয়ম আছে `HOW-TO-USE.md`-তে।
   - Chrome সংযুক্ত না থাকলে শুধু থাম্বনেইল দেখা যায়। তখন ক্লিপ বা স্ক্রিনশটও দিন।
4. রেফারেন্স শুধু **স্টাইল বোঝার জন্য**। অন্যের ফুটেজ, মিউজিক বা লোগো আপনার ভিডিওতে বসানো হবে না।

কোনো একটা ভিডিওর জন্য বিশেষ রেফারেন্স হলে সেটা ওই প্রজেক্টের `reference\` ফোল্ডারে রাখুন।
